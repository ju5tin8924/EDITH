# EDITH Platform — Visual Studio & Web Portal Run Guide

Please refer to the full execution guide in [`HOW_TO_RUN.md`](HOW_TO_RUN.md):

* **Backend:** Launch [`Edith.slnx`](../../Edith.slnx) in Visual Studio 2022 with `Edith.Gateway` as Startup Project (`http://localhost:5000`).
* **Frontend:** Run `cd src/Web/edith-portal && npm run dev` (`http://localhost:3000`).
* **Health Check:** `http://localhost:5000/health`.
